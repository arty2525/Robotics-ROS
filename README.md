# Robotics-ROS — วิชาวิทยาการหุ่นยนต์

เว็บไซต์สื่อการเรียนรู้รายวิชา **วิทยาการหุ่นยนต์** แยกออกจากโครงการ AI Hand Quest และ Arty-ROS2 โดยอิสระ

**แผน:** 20 สัปดาห์ สัปดาห์ละ 3 คาบ (วันหนึ่ง 2 คาบ อีกวันหนึ่ง 1 คาบ) รวม 60 คาบ คาบละ 50 นาที — ระบุ 1.5 หน่วยกิตตามข้อมูลของผู้สอน (ควรตรวจเทียบหลักสูตรสถานศึกษา)

## หน้าใช้งาน

- [Dashboard ผลประเมิน](https://arty2525.github.io/Robotics-ROS/dashboard.html) — รายวัน รายสัปดาห์ รายภาคเรียน รายบุคคลและกราฟพัฒนาการ (ใช้รหัสครู)
- [หน้าเว็บบทเรียน](https://arty2525.github.io/Robotics-ROS/) — แผนรายคาบ ใบกิจกรรม ข้อสอบก่อน–หลังเรียน ห้องทดลอง
- [ห้องเรียน VR 3D](https://arty2525.github.io/Robotics-ROS/vr.html)
- [สมุดประเมินครู](https://arty2525.github.io/Robotics-ROS/gradebook.html) — ใช้รหัสครูร่วมกับระบบประเมินเดิม ระบบบันทึกอยู่ในตาราง Supabase แยก
- [คู่มือครูและคำสั่ง ROS](COURSE_GUIDE.md)

**หมายเหตุ:** แบบทดสอบหน้าเว็บยังเก็บผลใน localStorage ของเครื่องผู้ใช้ ไม่ใช่ข้อมูลส่วนกลาง ผู้สอนต้องส่งออกคะแนนและสำรอง ส่วนสมุดประเมินของครูมีการตรวจรหัสและเก็บข้อมูลบน Supabase อยู่แล้ว ไม่ควรกรอกเลขประจำตัวประชาชนของนักเรียน
